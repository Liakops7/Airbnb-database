# Airbnb Database

This repository contains a **relational database schema** inspired by the Airbnb platform, implemented using SQL.

> This is an older academic project uploaded for reference. The design and implementation were part of a learning exercise.

---

## 🧠 Project Overview

The goal of this project is to model the core entities and relationships of an Airbnb-like system, focusing on database design rather than application logic.

The database covers concepts such as:
- Users (hosts and guests)
- Properties / listings
- Reservations
- Reviews
- Relationships between entities

The emphasis is on **entity-relationship modeling**, normalization, and correct use of relational constraints.
